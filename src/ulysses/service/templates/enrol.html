The key is made in this browser and cannot be copied out of it. Ulysses only receives the public half. Use this same browser to sign contracts and confirm actions.

Enrol

  1. This browser makes an Ed25519 key pair with WebCrypto, marked non-extractable.
  2. The private half stays in this browser's storage under the name {{ name }}.
  3. The public half is sent to the contract service and registered for {{ name }}.

Signing contracts later happens on the contract's own page, in this same browser.

What a signature here does

A contract signed with this key lets the agent start its experiment. A confirmation signed with it lets the service make the one Flagsmith call the contract allows when it fires. Nothing else.

No WebCrypto Ed25519?
